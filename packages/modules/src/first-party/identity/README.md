# Identity

## 目的与非目标

把平台发送者和聊天范围正规化为稳定身份事实；不实现认证、权限或回复策略。

## 消费和产生

消费入站文本，产生聊天范围、平台账号、人物解析及人物上下文原子。

## 数据流与边界

平台 ID 保持为外部事实，模块通过追加式绑定建立 canonical 或 ephemeral 身份。

## Settings

当前使用严格空设置。

## 可靠性、幂等和失败行为

同一入站只提交一个身份终态；无法解析时显式记录降级状态。

## 日志与可观测性

记录范围和人物解析状态，不输出平台凭据。

## 典型场景

Heartflow 在冻结 turn context 前等待每条入站的身份终态。
