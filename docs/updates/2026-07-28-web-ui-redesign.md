# 2026-07-28 Web UI 工作区改版

## 概述

本次更新在不改变 API 网关协议的前提下重构 `apps/web`。界面参考 AstrBot 控制台的工作区组织方式，将连接配置从常驻表单移动到独立抽屉，并增加会话导航、状态反馈和移动端侧栏。

## 变更

- 新增深色工作区侧栏，集中展示当前会话、消息数量和网关状态；
- 新增会话创建与本地消息清空操作；
- 新增连接设置抽屉，管理网关 URL、Bearer Token 和会话 ID；
- 重构空状态、消息提交状态、错误提示和输入区；
- 增加桌面和移动端响应式布局；
- 对图标按钮补充可访问名称与悬浮提示；
- 使用容错 storage 写入，浏览器禁止存储时不阻断页面交互；
- 保留原有 `GET /healthz` 和 `POST /api/v1/messages` 请求契约。

## 不包含

- 不新增模型路由、provider 配置或 API key 输入；
- 不实现机器人回复、SSE、消息历史或持久会话；
- 不新增管理 API、角色权限或操作审计；
- 不改变 API 网关的认证和参数校验行为。

## 验证范围

- Web TypeScript 类型检查；
- 现有 API client 单元测试；
- Vite 生产构建；
- Prettier 格式检查；
- `1440x900` 桌面视口与 `390x844` 移动视口人工截图检查。
