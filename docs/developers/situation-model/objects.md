# 对象与关系

模型以同一个 Agent 为连续性主体。群、私聊和本地对话提供情境地址，不创建独立的人格副本。

## 信息与情境

**证据** — 一次已接纳的信息。保存来源、陈述者、发生时间、接收顺序和所属情境。更正通过新证据引用旧证据，原文不可覆盖。稳定身份重复且内容相同的接收是幂等操作。相同身份对应不同内容时拒绝接纳。

**总背景** — 所有已启用入口的共同信息视图。来自其他群、输入框、工具或召回的信息均进入背景。来源情境和读取权限仍逐项保留，不根据昵称合并人物。

**当前情境** — 本次关注的具体场景。其他场景的新信息不隐式切换焦点。输入框在提交时固定目标情境，同时更新总背景和目标情境。

**召回** — 带版本的派生背景。来源不足、过期和结果缺失需要显式表达。召回变动不能伪装成用户新发出的消息，也不能改写已冻结的请求。

总背景和当前情境引用同一份证据。渲染时只展开一次原文，其他位置保留引用。全部入口进入总背景，不代表全部历史在每次请求中同时展开。

## 观察与请求

**情境帧** — 一致读取边界上的总背景、当前情境和精确召回版本。时间是冻结时刻，不在请求执行中刷新。

**观察** — 对声明范围的完整读取。缺页或必需来源缺失时保持未完成。它证明输入范围完整，不证明模型已经正确理解。

**请求清单** — 模型步骤实际使用的情境帧、检查点、行动范围和策略版本。重试使用同一清单，不能悄悄纳入后来信息。

观察进度与模型步骤进度分别记录。变化说明以主行动线上前一个已完成模型步骤为基准，不以最后接收的消息或最后形成的快照为基准。

## 行动与连续性

**行动记录** — 明确意图、目标、当时的情境帧、关键依据、依赖和执行结果。规划完成、执行开始、结果确认与结果已处理是不同事实。

**主行动线** — 同一 Agent 的连续行动及因果关系。工具可以在后台运行，模型决策按主线串行提交。切换当前情境不重置这条主线。

**连续性检查点** — 对可归档行动片段的有来源归纳。保留当前任务所需状态及历史覆盖范围。检查点不能自行宣告工具成功，也不能消除未知结果。

公共类型和共同样例位于仓库的 `contracts/situation-action/v1`。类型描述传输与存储边界，状态转移规则仍由本文及相邻专题约束。
