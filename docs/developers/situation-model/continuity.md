# 行动连续性

整个 Agent 维护一条逻辑行动线。当前情境可以变化，已记录的行动身份、状态和实际结果保持连续。

## 保留当时的依据

每个行动绑定产生它的请求清单和情境帧。行动依据记录展开必要证据，保存证据身份与原情境。后来更新情境不会改写这些内容。

执行前检查行动是否被替代、依赖是否仍成立以及权限是否有效。只因无关消息到达就取消工作，会使长期任务持续饥饿。明确停止、更正与权限变化需要独立处理。

行动结果成为新证据，再进入后续情境。模型提出行动不等于执行成功，工具完成也不等于结果已经被后续步骤处理。

## 近期轨迹与检查点

近期轨迹保留完整行动单元。未完成任务、未知结果、未兑现承诺和未闭合工具交互保持可见。已完成行动仍保留一个可配置的近期窗口。

归档以闭合片段为单位。只有结果已处理、工具已配对、相关依赖已保存的片段可以移入检查点。存在较早未知行动时，允许归档其他独立片段，不要求整个历史前缀全部完成。

检查点记录前一版本与覆盖范围，保留已经登记的任务、承诺、等待条件和结果。检查点从账本确定性生成。进入 Heavy 前不从证据推断新任务、承诺或理由，也不增加模型摘要步骤。

检查点发布和轨迹归档在同一事务中完成。恢复只使用已提交版本。被归档的原文仍可查询，并能沿行动、情境帧和证据回溯。

## 原生模型接续

调用前保存实际输入。调用完成后保存原生消息、服务提供的推理项和必要协议元数据，再关联情境帧、行动决定及实际结果。沉默同样保存原生返回，不要求另写沉默理由。

可读推理与服务摘要按其实际类型展示。没有提供时显示“未提供”。不可读的接续数据保持原形，只有对应协议可以使用。服务不支持的推理接续不转换成普通正文。旧记录缺少原生数据时明确标记，不补造历史。

情境更新只替换情境内容。需要继续使用的原生消息和完整工具交互保持可用。Light 的返回与 Heavy 的返回分开保存。取消、已被替代或中断分支的迟到返回不进入当前接续。

原生消息纳入预算。自行裁剪时以完整、闭合的交互片段为单位。未完成行动、未知结果和未配对工具必须保留。必要内容仍超限时显示受阻。

## 跨情境与长期任务

群 A 的查询执行期间，群 B 可以更新总背景。调度器之后可以关注群 B，但 A 的任务和结果仍存在于主行动线。工具结果明确关联原行动，不能被归入后来选中的场景。

长任务可以归档已经闭合的子段，同时保留尚未完成的状态和必要证据。连续性要求可恢复的语义状态，不要求每次请求重放整个工具输出。

等待拥有持久期限或明确条件。重启后恢复同一等待身份，不创建重复 timer。预算或外部条件导致阻塞时，同样保留任务与原因。

## 历史查询

按行动身份、范围和情境查询原始行动与证据。旧帧按原版本返回，不用最新召回替代过去使用的记忆。查询结果是有来源的背景，不修改已确认进度。

物理模型会话可以在安全点轮换。逻辑 Agent、检查点和行动身份继续使用。原生工具调用尚未闭合时不得轮换，避免伪造或丢失调用结果。

## 滚动情境与冻结快照

情境通过稳定的 `sceneId` 标识。新证据形成新的 `SituationFrame`，当前入口随之指向新帧。旧帧保持不变，模型调用继续引用调用时的 `frameId`。模型完成或投递结果更新行动状态，不凭空增加一份情境快照。

展示层从按注册顺序排列的帧派生情境更新序列。它不增加模型摘要，也不改变共享契约 `1.0.0`。

- **sceneId** — 同一情境的稳定标识。
- **headFrameId** — 当前窗口内最新冻结帧的标识。
- **updatedAt** — 最新帧的冻结时间。显示顺序仍以注册顺序为准，不按原始消息时间重新排序。
- **revisions** — 该情境的冻结帧引用，最新在前。相同帧 ID 只出现一次。Kaguya 页面将帧按时间轴方向显示，较早帧位于左侧。
- **frame.changes** — 新证据与失效证据的原始引用。变化数量来自这些记录，不是模型对情境的解释。

两端沿用已有最近 50 份帧的读取窗口。Kaguya 在页面可见时，每次请求结束后等待 3 秒再读取。DSH 继续使用宿主订阅。接续预算、原文账本和模型会话不受展示窗口影响。

显示状态与运行状态分开。Kaguya 默认跟随最新帧，标为 `TICK 0`。拖动时间轴或使用前后箭头后固定查看所选帧。即使该帧后来移出最近窗口，也保留本次查看的快照。“回到最新”重新启用跟随。回看不改变 Agent 的执行焦点。

## 有界的序列视图

Kaguya 使用固定的上下分区。上方控制台常驻显示当前情境、其他会话背景和召回。下方使用带刻度的 tick 时间轴，行动按选中 tick 及前后各两个 tick 分栏展示，可读推理直接显示在行动栏内。

目标路由候选、冷启动、等待预算和积压状态压缩显示在顶部。行为规则、平台策略和人物背景放在“上下文”浮动按钮中，默认收起。它们来自该 tick 已保存的请求，不用当前模板重新生成。

控制台与行动内容各自滚动，标题和操作按钮位于滚动区域外。窄屏调整分区排列并保留高度上限。自动更新保留已选快照及阅读位置，不随记录数量持续撑长页面。刷新失败时保留上次内容，“上次刷新”只记录成功读取的时间。
