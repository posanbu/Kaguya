# 实现映射与验收

本页区分规范、库级实现和真实运行链。结构测试通过不证明模型能正确处理群聊，也不证明外部投递已经验证。

## 公共契约

契约版本为 `1.0.0`。仓库 `contracts/situation-action/v1` 保存类型、JSON Schema 和共同样例。两端独立实现状态与装配，只复制契约数据和测试样例。

核心对象为 `SituationFrame`、`ActionRecord`、`ContinuityCheckpoint` 和 `ContextManifest`。版本改变时更新校验值与支持报告。持久数据格式、装配策略和 DSH 兼容版本分别记录。

插件固定契约版本和文件校验值。`upstream.json` 记录来源。发布时必须将 `sourceCommit` 固定为包含契约文件的提交。工作树同步阶段可以保持空值，但不能把不含契约的基线提交当作来源提交。CI 检查上游漂移，不在运行时下载规范，也不自动修改另一个仓库。

## Kaguya 映射

默认链已经接入 `agent.situation`。它按注册边界冻结 `SituationFrame`、原始证据和已有行动状态，再触发注意模块和独立 Light Router。Light、Heavy 共用同一冻结事实。窗口和请求结构见[Prompt 装配](../prompt-assembly)。

行动仍由既有 Information Atom 表达。`agent.router.turn.*`、模型任务和投递回执共同形成确定性的连续性投影。默认链没有把这些记录伪装成完整的可移植 `ContextManifest`。公共装配库继续用于契约测试与其他宿主接入。

原生返回使用独立运行时扩展 `version: 1`，保存在模型任务终态。取消和被替代结果不接续。投递开始标记与实际回执分开保存，重启后未知结果不自动重发。

网页第二个选项卡“情境”位于 `/situation`。只读接口 `/api/v1/inspection/situation` 沿用 Inspection 的认证、脱敏和 `no-store` 边界。默认展示最近 50 份帧、60 次调用，以及最新冻结记录中的未闭合行动。原始历史继续通过检查接口查询。不可读的原生协议数据不在概览接口中返回。

## DSH 映射

独立插件仓库名称为 `dsh-kaguya-scene`。一个逻辑 Agent 使用一条主行动线。OneBot 与独立主页的本地输入经过统一准入，时间、召回和工具结果作为内部信息源。

插件 `0.4.1` 在 DSH 侧栏提供独立 Kaguya 入口。主页显示行动、本地对话和运行控制，右上角信息按钮展开情境地图、Observer、记忆和历史。本地输入固定属于 `local:main`，与群消息共用持久唤醒队列。浏览器订阅不拥有 Agent 生命周期，离开页面后后台继续运行。

安装补丁仅增加插件与专用预设。创建、恢复和轮换时显式挂载该预设，普通对话继续使用原有配置。首次启用意图与暂停状态持久保存。暂停阻止新模型步骤和新投递领取，接收仍持续。已有账本接续原逻辑身份。

插件复用官方循环、Session、工具协议和界面。情境、检查点、等待和发送队列保存在事务存储。Session 日志关联稳定身份，模型上下文替换有日志可回放。

首个兼容基线是官方桌面运行时 `0.2.1-rc.2`。测试使用该版本的官方循环、Session 和工具服务，验证官方 Remote 准入、原文保存、普通 Session 隔离、暂停恢复、上下文替换和工具配对。模型响应使用确定性测试适配器。OneBot 测试使用本地协议服务器。2026-10-20 已通过官方 CLI 安装到本地 desktop profile，并在真实桌面验证页面加载、面板开关、焦点恢复、草稿保留和输入冻结。真实模型调用因该 profile 缺少 `deepseek-official` API key 受阻，未形成模型返回。真实 QQ、模型质量和连续墙钟运行尚未验证。

新增观察与记忆插件的范围、失败策略及 issue 对照见 [DSH 观察与记忆](./dsh-cognition)。DSH 继续使用已有 Observer，不新增第二个 Light。它的模型结果与主 Session 返回分别保存。

## 滚动界面更新（0.4.1）

Kaguya 使用常驻控制台与 tick 时间轴，支持跟随最新和固定回看。回看快照移出最近窗口后仍保留所选内容。行动区显示选中 tick 及附近行动，行为规则、平台策略与人物背景通过浮动按钮展开。结构与边界见[滚动情境与冻结快照](./continuity#滚动情境与冻结快照)。

Kaguya 控制台与行动内容各自滚动，新增记录不会持续撑长页面。当前界面固定深色样式，桌面与 390 像素窄屏已完成浏览器检查。Runtime 到只读接口的集成测试使用确定性模型，验证冻结帧、Light/Heavy 行动及原生返回可被查询，不证明真实模型的回答质量。

## 验收样例

1. 多群和输入框共同进入背景，当前情境保持明确归属。
2. 消息迟到、重复和分页不丢失未处理范围。
3. 情境刷新数千次后只有当前帧驻留，行动依据仍可解释。
4. 更正使待发送内容失效，已执行结果保持原样。
5. 检查点只保留已登记的未知结果、任务、承诺和等待。
6. 重启与安全轮换后不重复派发外部行动。
7. 必需输入超预算时明确阻塞，不截断工具配对。

长时间验证分为加速的 72 小时事件回放和真实 72 小时运行。前者验证时序、预算和恢复，不能代替后者的资源增长、网络波动或真实交互质量。

## 本次验证记录（2026-10-20）

Kaguya 类型检查与相关流程、持久任务恢复、焦点、只读接口回归通过。全量测试首次扫描 1597 项，随后修正旧断言并在允许本地监听的环境重跑服务器测试。尚有一项未改动文件的既有架构检查失败：`napcat-capture.ts` 使用检查器禁止的 `messageId` 标识。没有将本次结果记为全量通过。

DSH Scene 的 38 项测试通过，其中本地 OneBot 监听测试在允许监听的环境重跑。Observer 的 2 项测试、构建和契约检查通过。合成界面覆盖桌面与窄屏、浅深主题、空态、离线、长内容、预算受阻和键盘焦点。真实桌面结果与模型配置阻塞见上文，未用合成模型替代真实接入结论。

官方 CLI 的 peer 检查报告 profile 缺少宿主 peer 包，但真实桌面已通过内置运行时加载插件。此次没有另装或升级宿主包。
