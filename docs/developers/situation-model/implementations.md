# 实现映射与验收

本页区分规范、库级实现和真实运行链。结构测试通过不证明模型能正确处理群聊，也不证明外部投递已经验证。

## 公共契约

契约版本为 `1.0.0`。仓库 `contracts/situation-action/v1` 保存类型、JSON Schema 和共同样例。两端独立实现状态与装配，只复制契约数据和测试样例。

核心对象为 `SituationFrame`、`ActionRecord`、`ContinuityCheckpoint` 和 `ContextManifest`。共享文件变化时同步类型、校验和共同样例。持久数据格式、装配策略和 DSH 宿主基线分别记录。

插件固定契约文件校验值，`upstream.json` 记录来源提交。现有草案以 `7edca245` 为基线，通过本地源码依赖与构建验证，不生成发布归档。运行时不下载规范。

## Kaguya 映射

默认链已经接入 `agent.situation`。它按注册边界冻结 `SituationFrame`、原始证据和已有行动状态，再触发注意模块和独立 Light Router。Light、Heavy 共用同一冻结事实。窗口和请求结构见[Prompt 装配](../prompt-assembly)。

行动仍由既有 Information Atom 表达。`agent.router.turn.*`、模型任务和投递回执共同形成确定性的连续性投影。默认链没有把这些记录伪装成完整的可移植 `ContextManifest`。公共装配库继续用于契约测试与其他宿主接入。

原生返回使用独立运行时扩展 `version: 1`，保存在模型任务终态。取消和被替代结果不接续。投递开始标记与实际回执分开保存，重启后未知结果不自动重发。

网页第二个选项卡“情境”位于 `/situation`。只读接口 `/api/v1/inspection/situation` 沿用 Inspection 的认证、脱敏和 `no-store` 边界。默认展示最近 50 份帧、60 次调用，以及最新冻结记录中的未闭合行动。原始历史继续通过检查接口查询。不可读的原生协议数据不在概览接口中返回。

Kaguya 使用常驻控制台与 tick 时间轴，支持跟随最新和固定回看。回看快照移出最近窗口后仍保留所选内容。控制台和行动区分别滚动，结构与冻结边界见[滚动情境与冻结快照](./continuity#滚动情境与冻结快照)。

## DSH 映射

现有 Scene、Observer、Memory 三个插件按 Kaguya `7edca245` 的已实现设计同步，版本分别保持 `0.4.1`、`0.2.0`、`0.1.1`。本轮同步的草案尚未安装或发布，不生成归档、不实施升级或迁移。历史版本的安装记录不表示当前草案已安装。

Scene 统一输入、账号身份、生命周期、冻结情境、主行动线和逐段投递。Observer 只选择 message、wait 或 silent。Memory 提供统一节点图、来源、固定摘要、独立形成进度和受限补查。配套插件通过 `sceneRuntime` 协作，不访问 Scene 私有表。具体行为与范围见 [DSH 观察与记忆](./dsh-cognition)。

独立主页继续使用 DSH 原生主题与官方 Slot、Remote。主区显示当前活动、十分钟时间线和本地输入。信息面板按冻结请求展示记忆、实际 Prompt 和原生返回，历史缺失字段显示“未记录”。记忆支持查询、修订、锁定和来源追溯。

测试宿主基线为官方 DSH `0.2.1-rc.2`。本地集成调用官方循环、Session、工具和 Remote 服务，模型使用确定性适配器。OneBot 使用本机协议服务器。浏览器检查使用合成页面。结果不能视为实际 DSH 安装、真实 QQ 或真实模型验收。

## 验收样例

1. 多群和输入框共同进入背景，当前情境保持明确归属。
2. 消息迟到、重复和分页不丢失未处理范围。
3. 情境刷新数千次后只有当前帧驻留，行动依据仍可解释。
4. 更正使待发送内容失效，已执行结果保持原样。
5. 检查点只保留已登记的未知结果、任务、承诺和等待。
6. 重启与安全轮换后不重复派发外部行动。
7. 必需输入超预算时明确阻塞，不截断工具配对。

长时间验证分为加速的 72 小时事件回放和真实 72 小时运行。前者验证时序、预算和恢复，不能代替后者的资源增长、网络波动或真实交互质量。

## 草案验证记录与限制

各插件的 `verification.md` 保存 2026-10-25 的类型检查、构建、契约、状态机、官方服务、浏览器和加速回放结果，并分别列出修复过的失败项与未验证项。公开摘要见 [#288](https://github.com/posanbu/Kaguya/issues/288)。2026-10-29 的文档复核读取了这些记录，没有重新执行插件测试。

这些记录不包含真实模型效果、真实 QQ、当前草案的实际 DSH 安装或连续 72 小时墙钟运行，不能据此报告模型质量或成本收益。Kaguya 本身的运行链验证与 DSH 草案验证分别记录。
