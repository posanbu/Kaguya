# 记忆形成与整理

Memory 形成由 `memory.native` 统一运行。契约和检索边界见 [Memory 模块边界](../memory.md)。

## 来源与批次

身份解析完成后，同一会话的真人文本进入持久化来源队列。默认达到 8 条或等待 60 秒触发，单批最多 24 条。认领、批次内容和终态保存在数据库中，模型请求沿真实来源冻结。

批次是处理单位，不是经历单位。模型可以补充已有经历、修正结论或返回空结果。来源缺失、作用域不符、版本冲突和手动锁定都会阻止自动发布。

## 层级与修订

同一对象和作用域的 level 0 是可选的唯一摘要。更具体的记录使用较大的 level，通过 `summarizes` 连接。修订保留原节点 ID，增加 revision。节点、边、全文索引和审计记录原子提交。

修改细节但没有同步更新的祖先摘要会失效，退出固定注入。自动形成不覆盖手动锁定正文。模型输出必须区分自述、观察和推断，不能把旁观者猜测作为当事人的确定事实。

例如，B 先说“戒了咖啡”，后更正“晚上不喝，白天还喝”。整理应更新该经历及相关摘要，保留两次来源。C 的相反猜测应保留归属，不能直接替代 B 的自述。此类归属质量仍需要模型场景评估，结构校验不能证明推断正确。

## 固定摘要与召回

基本人物关系、群聊属性和稳定表达习惯若被整理为 level 0，即在适用场景无条件注入。它们不经过关键词、embedding 或 topK 筛选。具体经历可由文本、向量或显式引用命中，再沿图展开。

形成过程失败时保留原始来源和可见的失败批次。没有派生记忆不表示事件没有发生。旧回合始终读取保存的版本，不用后来的修订改写过去的模型输入。

## 当前边界

来源适配主要覆盖已归一身份的真人文本、成功投递的自身消息，以及 QQ 插件提供的文字上下文推断。工具、音频、图像和外部来源撤回需要专门的来源契约，不能把意图或视觉猜测写成已经发生的经历。

索引可以自动重建。模型形成质量、人物归属和长期整理质量需要独立评估，不以 schema 验证或检索功能清单代替效果证据。
