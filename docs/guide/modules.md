# 模块配置

模块负责聊天中的不同工作，例如判断是否接话、编写回答或学习表达习惯。日常使用无需理解模块之间的内部流程。

## 在哪里修改

1. 打开“检查 → 模块”，选择目标模块。
2. 在全局配置中修改参数，按页面显示的范围填写。
3. 普通参数保存后，到“配置生效管理”点击“应用当前配置”。启停变更，以及原始记忆和 NapCat 的设置，需要重启。

模块配置属于工作区，切换顶栏 Profile 不会切换这些值。模板的保存与恢复默认需要重启，详见[角色与回复风格](./persona)。

## 常用模块

**Heavy `heavy.default`** — 生成回复正文，固定使用 Profile 的 `heavy` 档位。

**Router `router.default`** — 认领并冻结观察后的输入，调用内部 Light 决定发送、等待或静默，并管理 Focus 租约。Light 固定使用 Profile 的 `light` 档位；两个档位可以指向同一实际模型。

**注意力 `attention-arousal.default`** — 控制 @、叫名和持续关注相关设置。

**短心跳 `heartbeat.default`** — 等待连续输入，处理延期和重新规划的时间。

以上三个模块的参数见[发言频率与等待](./reply-settings)。

**表达学习 `memory.expression.default`** — 从聊天中学习并选择表达习惯。`batchSize` 默认 `8`，范围 `2–24`，控制一次学习所需的消息批次大小；调大通常需要积累更多消息。

**身份 `memory.identity.default`** — 默认无可调 settings，通常保留启用。Focus 是 Router 的内部职责，没有独立实例；`memory.native` 与 `memory.mem0` 在目录中标记“未完成”，没有实例或开关。

## 启用与停用

网页中的启停开关写入 `cordis.yml` 的 `disabled`，重启后生效。页面分别显示期望状态与当前运行状态。模块之间存在依赖，不能把关闭任意模块当成关闭单项功能：例如默认消息编写依赖表达模块，关闭表达实例可能使下次启动失败。

若只想让机器人安静一些，先调整频率或静默模式；若不想使用历史记忆，在概览关闭“原始记忆”。此时不再写入新的原始消息。

## 保存冲突或应用失败

**版本冲突** — 其他页面已经保存了新版本。先复制需要保留的输入，重新读取后再编辑。

**参数无效** — 按字段旁的错误提示修改。不要通过删字段绕过校验。

**依赖不满足** — 检查刚停用的模块，恢复依赖后再应用。

## 手工编辑文件

启停配置保存在 `<KAGUYA_CONFIG_ROOT>/cordis.yml`。每个内置插件条目使用固定 `id`、`name` 和布尔 `disabled`；必需服务不可禁用，模块条目与内置实例一一对应。实例参数保存在 `modules/<instanceId>/config.json`，每个文件只包含 `version: 1`、`instanceId`、`definitionId` 和 `settings`。手工修改前停止服务并备份，完成后重新启动。

新建配置目录会生成默认插件树与实例文件。插件树在启动时读取一次；本阶段只接受内置插件，不装载外部包，也不支持运行时重载。
