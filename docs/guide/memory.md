# 记忆配置

在侧栏打开 **记忆**，管理人物关系、会话属性、自我认识、经历和表达。这些视图读取同一份记忆图，共用正文、连结和修订历史。

## 开关与配置

概览中的 **Memory** 开关控制 `memory.native`，默认关闭。保存开关或模块设置后，重启生效。关闭不会删除记忆，也不影响普通回复和近期原始事件上下文。

在 **检查 → Memory** 查看待形成来源、批次、版本发布及最近索引状态。该页提供语义辅助检索和语言／字面相似检索两份独立配置。两者默认关闭。启用时填写已有 AI 服务的 `providerId`，以及 embedding 模型的 `modelId`、`revision`、`dimensions` 和 `timeoutMs`。不在这里填写密钥，也不会自动使用聊天模型。

向量服务或索引不可用时，图和文本检索继续工作。索引状态记录最近一次运行，不替代模块的实际启用状态。

## 摘要与细节

**level 0 —** 对象在某个适用范围内唯一的有效摘要。适合基本人物关系、群聊属性、稳定的自我认识和表达习惯。只有值得持续注入的内容才设为 0，不要求每个人都存在摘要。

**其他 level —** 按需检索的具体记忆。数值越大，表示相对更具体的层级。level 不表示重要性，不是搜索加权分数。

姓名、关系和偏好合入同一人物摘要。用 `summarizes` 连结摘要与细节，方向必须从较小 level 指向较大 level。普通语义连结使用独立的关系类型。

## 编辑记忆

选择 **新增记忆**，填写类型、对象 ID、适用范围、level 和正文。对象 ID 必须与运行时使用的对象一致。自身使用 `self:kaguya`，人物使用 `person:` 加身份页中的人物 ID。人物详情提供直达该对象记忆的链接。

默认将具体经历保留在来源会话范围。`shared` 仅适合稳定称呼、自己与人物的稳定关系、自我认识和自己的表达习惯。群内第三方信息和 QQ 表情资源应保留来源范围。

选择 **锁定** 后，自动整理不能覆盖该节点正文。编辑通过版本发布保存，在下一回合生效。已有回合保留当时版本。遇到版本冲突，刷新后再编辑。新体系的 **归档节点** 保留历史，停止在线召回。

图谱沿用拖拽、缩放、连线和一跳关联操作。每页最多显示 100 个节点及 1000 条内部关系。类型、状态、level、正文、标签和时间筛选共同限制当前视图。

## 在情境中核对实际注入

打开情境页的 **上下文** 浮动按钮，选择 tick 和 Light／Heavy 请求。人物背景、群聊属性、自我认识和表达习惯展示该请求实际保存的固定摘要。

人物范围覆盖本轮冻结的全局背景和当前会话背景中的所有已明确关联人物，包括历史发言者、明确提及对象和回复对象。即使某人本轮没有发言，也会读取其适用摘要。跨会话只读取当前范围允许使用的内容或共享摘要。昵称相同不会合并身份。

“无条件注入”是在对象、适用范围和有效版本已经确定之后，不再经过关键词、相似度或 topK 筛选。例如：

- 对方只发了“早上好”，适用的基本人物关系仍进入人物背景。
- 群聊具有持续有效的讨论规范，群聊属性直接进入固定上下文。
- 自身有稳定的简短表达习惯，表达条目直接进入固定上下文，不作为事实证据。

主界面的 **召回** 区展示动态结果。某次经历可以通过文字或 embedding 命中，再沿图中 link 展开相关证据。相似文本不能证明两个人是同一个人，也不能自动产生事实关系。

固定摘要影响 Light 可见的背景，由 Light 判断是否回复。它不会直接改变回复概率或唤醒规则。

## 旧数据

Memory 从新的记忆起点开始。人物画像、独立表达库、原文文档库、旧向量索引和 Mem0 实现已删除，不提供迁移或历史查询入口。原始事件账本与 Raw 事件投影仍保存证据，旧派生内容不能进入在线背景。

模块配置使用当前默认定义。启用记忆时配置 `memory.native`。

形成失败或发布被拒绝时，在运行检查页展开“失败批次与重试”。确认来源或锁定冲突已经处理后，选择“重新排队”。旧失败记录会保留。模块停用时不能从此入口重试。

## 持续维护人物信息

人物摘要可以包含有来源的基本信息、称呼、稳定偏好、交往事实和关系边界。Memory 同时读取消息正文、发言者、平台昵称、群名片、明确提及及回复对象。平台名称只是观察，不能证明真实姓名或彼此认识。

关系使用具体事实和自然描述。例如：“此前在本群见过其发言，现有来源未记录相互介绍。”系统不按出现次数升级关系，也不把账号建档当成认识。本人自述、第三方描述和推断保留各自来源。更正修订原节点，手动锁定的内容不被自动覆盖。

情境中的人物卡片显示所选请求实际注入的摘要原文、范围、来源和版本。账号解析状态放在展开详情中。动态经历留在“召回”区。查看当前记忆需要点击独立链接，不会替换历史请求内容。

对于见过但尚不认识的人，模型按已有信息自然交流，保持自身角色的表达。普通问题正常回答。只有回复依赖缺失信息时，才询问必要内容。资料缺失不等于第一次见面。
