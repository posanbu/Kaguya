# 网页管理与聊天

服务启动后，打开终端打印的完整 **Kaguya access URL**。默认网页和 API 都在 `http://127.0.0.1:3000`，无需单独启动前端。

## 登录与重新连接

完整链接带有 `#gatewayToken=...`，相当于管理凭据，请勿分享。每次重启 Kaguya 都会生成新令牌；出现“访问受限”或 `401` 时，重新打开当前终端中的新链接。

仅刷新旧链接不会更新令牌。服务默认只允许本机访问，远程服务器的访问方法见[运行参数](./runtime#远程访问)。

## 管理配置

顶栏 Profile 选择器用于切换查看和编辑对象。配置页编辑模型、时区、Memory 与白名单，“Gateway / Adapter”管理 NapCat；“检查 → 模块”编辑模块参数与模板。

保存后进入“配置生效管理”，核对当前选中和当前生效的配置，再点击“应用当前配置”。模板与进程参数按提示重启。详见[配置概览](./configuration)。

## 与机器人聊天

在“消息”页输入文字，按 `Enter` 发送，`Shift + Enter` 换行。回复完成后整条显示，当前不逐字输出。

**刷新页面** — 浏览器保留会话标识，从服务端恢复记录。

**新对话** — 创建独立会话。旧记录仍保留在服务端，但当前网页没有旧会话列表。

**切换页面** — 未发送草稿会保留；刷新页面则清空草稿。

**发送未确认** — 网络异常时，页面会继续检查服务端是否收到。重新发送会提交一条新消息，避免连续重复点击。

## 查看运行状态

“Gateway / Adapter”分别显示服务、Runtime、Web 与 NapCat 的状态。网页能打开不代表模型或 QQ 已经可用，遇到问题先查看这里的原因提示。

需要进一步排查时，再进入检查页面或开发者控制台查看请求和投递结果。普通使用无需阅读信息图或理解内部编号。

持续没有回答时，按[常见问题](./troubleshooting)检查配置是否生效、是否选择回复，以及模型请求是否成功。
