# 跨会话消息

Kaguya 可以通过 NapCat 向可达的群或好友发送消息。先按[接入 QQ](./napcat)连接账号，并允许目标的出站权限。

## 在聊天中提出请求

在已获准入站的群聊中，可以说：

- “私聊我：会议三点开始。”
- “发到协作群：会议三点开始。”
- “告诉小红：会议三点开始。”

目标唯一、可达且获准出站时，机器人可以生成正文并发送，不需要再到网页确认。请求仍经过对话参与判断，不保证每次都执行。“私聊我”以本轮最后一位发言人为准，普通回复继续发在当前会话。

系统只使用本次明确要求发送的内容，不自动复制来源群的全部历史或记忆。

## 从管理网页发送

1. 打开“跨会话消息”，加载并选择近期来源对话。
2. 使用完整名称、精确号码或描述查找目标，并明确选择一个候选。
3. 填写发送要求与允许使用的资料，点击“确认目标与发送要求，生成正文”。
4. 点击“刷新生成结果”，检查完整正文。
5. 点击“确认以上正文并发送”。

提交成功表示进入发送处理，实际成功或失败以开发者控制台的投递结果为准。

## 找不到目标或没有发送

**重名** — 补充更明确的目标；网页中手动选择，不会自动猜测。

**无法私聊** — NapCat 好友目录中需要存在可达账号，群成员不自动成为私聊好友。

**没有权限** — 检查目标是否在当前生效配置的出站白名单中。允许某个群入站，不等于允许给其中每个人发私聊。

**目录不可用** — 检查 NapCat 是否在线，再重新查询。

**请求过期** — 候选和批准有效期为五分钟。重启、重连、账号变化或应用配置后，点击“新建请求”重新查询。

聊天中无法确定目标时不会把原本要私聊的内容改发到来源群，目前也不会自动向来源群发送失败通知；需要在管理页面检查原因。
