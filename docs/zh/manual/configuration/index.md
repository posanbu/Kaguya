# 配置概览
## 📋 配置文件清单

MaiBot 有两个主要的配置文件，都放在 `config/` 文件夹里：

**`bot_config.toml`** — 机器人的基本信息、性格、聊天、记忆（含 A_Memorix）、学习、日志等全部主配置，[查看详情](./bot-config.md)
**`model_config.toml`** — AI 模型设置，设置麦麦使用的 LLM，[查看详情](./model-config.md)

::: tip 💡 小贴士
这些配置文件需要启动一次MaiBot之后才会生成。如果无法找到，请先启动一次。
:::

## 🔄 配置热重载范围

MaiBot 会监听 `bot_config.toml` 和 `model_config.toml` 的变化。是否需要重启，取决于该设置控制的是运行时行为，还是服务的启动方式。

**保存后自动生效** — 机器人人设、人格、聊天策略、回复频率、模型提供商、模型与任务分配会热重载。模型变更对后续请求生效；带重载回调的模块（含 A_Memorix、表情维护）也会收到更新。

**由插件运行时热重载** — 插件自己的 `config.toml` 有独立生命周期。运行时会监听它并调用插件配置更新钩子。启用、禁用、安装、卸载和源码更新一般不需要重启整个 MaiBot。

**需要完全重启 MaiBot** — WebUI 的启用/绑定/端口设置；`maim_message` 的绑定、端口和鉴权；MCP 服务器连接；进程级插件运行时的绑定或 IPC 设置在启动时建立，文件重载不会重新绑定。

::: tip 如何判断
保存后查看日志。出现成功的配置重载或插件更新消息，说明新值已生效。修改监听地址、MCP 连接或其他仅启动时生效的设置时，重启 MaiBot。
:::

## 🌐 WebUI 配置

如果你不喜欢手动改文件，MaiBot 还提供了网页版的配置界面（1.0.0 已内置 WebUI 配置界面）：

- 🌐 默认地址：`http://127.0.0.1:8001`
- 🖱️ 点点鼠标就能改配置
- 📱 手机、电脑都能用
