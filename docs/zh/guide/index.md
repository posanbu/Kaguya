# 使用指南

这里面向希望安装、配置和使用 Kaguya 的读者。当前页面先定义信息架构，具体操作细节将在功能稳定后逐步补齐。

::: tip 推荐顺序
第一次接触项目时，依次阅读“安装与启动 → 配置 Kaguya → 使用 Web UI”。
:::

## 适合谁阅读

**首次使用者** — 了解运行条件、启动方式和首次配置流程。

**维护者** — 查找部署、升级、备份和故障排查信息。

**体验者** — 了解 Web UI 当前能做什么，以及功能边界在哪里。

## 阅读路线

### 准备环境

从[安装与启动](./installation)开始，确认 Node.js、pnpm 和仓库状态。

### 完成配置

前往[配置 Kaguya](./configuration)，理解 Provider、模型层级和敏感信息的保存边界。

### 进入界面

通过[使用 Web UI](./webui)了解同源页面、Gateway Token 和当前交互能力。

## 内容状态

此分区已经具备稳定的目录和导航。后续新增内容时，应在中文页面完成事实核对，并同步更新英文镜像。
