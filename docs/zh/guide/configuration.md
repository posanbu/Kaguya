# 配置 Kaguya

Kaguya 的配置文档将围绕“配置来源、敏感信息、验证与生效时机”组织，避免把零散变量堆成无法理解的清单。

## 配置分层

### 服务配置

说明监听地址、端口、数据库位置、日志与代理信任边界。

### Provider 与模型

说明 Provider、模型目标、轻量/重量层级，以及配置保存后的生效方式。

### 平台连接

说明 NapCat 等可选连接的地址、身份、令牌与重连策略。

## 安全原则

::: warning 敏感信息
API Key、Gateway Token 和平台令牌不得写入公开 Markdown、截图、前端构建变量或 Git 历史。
:::
