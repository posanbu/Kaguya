# 使用 Web UI

Kaguya 的 Web UI 由统一 Server 同源提供，不需要单独配置第二个 Web 服务地址。

## 页面入口

开发和生产环境都通过 Server 的地址访问。具体端口、配置模式和认证方式以当前 Server 配置为准。

## 首次配置

当配置尚未完成时，页面应优先展示引导流程；完成配置后，Runtime 可能需要重启才能载入冻结后的 Provider 和模型信息。

## 当前交互边界

### 浏览器负责什么

浏览器负责展示状态、提交用户操作和呈现结构化错误。

### Server 负责什么

Server 管理 Provider、模型、密钥、Runtime 与数据持久化；这些敏感能力不应下放给浏览器。
