## 路线图规则

**已完成** — 有代码、测试或已发布页面作为证据。

**进行中** — 已有负责人和可跟踪的 Issue/PR。

**规划中** — 只有方向，接口和交付时间仍可能变化。

## 发布记录

后续版本页按时间倒序记录用户可感知变化、迁移要求和兼容性说明。

## 参与贡献

通过 GitHub Issue 确认范围，在独立分支完成修改，并通过构建、类型检查和相关测试后提交 PR。
