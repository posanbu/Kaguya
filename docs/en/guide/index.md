# User Guide

This section will contain installation, configuration, WebUI usage, and common workflows. The current pages are structural placeholders so the team can add real instructions incrementally.

## Recommended path

1. Read [Installation](./installation) to prepare the runtime and dependencies.
2. Continue with [Configuration](./configuration) to understand project settings.
3. Open [WebUI](./webui) for the future interface guide.

## What belongs here

- Steps for end users and operators.
- Copyable commands with expected results.
- Troubleshooting placed close to the relevant step.
- Links to deeper developer references only when needed.

::: tip Writing principle
Each page should answer one concrete task. Prefer a short executable path first, followed by explanations and edge cases.
:::
