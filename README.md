# Introduction

辉夜Kaguya是基于大模型的聊天智能体，是一个亲切真实的AI群友。

- **自然的交互方式**：不会长篇大论，不会分点回答，她只会与你们共同分享，共同吐槽，共同生活在群聊之中。
- **明智的发言时间**：懂得何时应该参与聊天，何时应该保持沉默。
- **不断进化的辉夜**：在聊天中不断理解群聊与世界，自主理解每个圈子里的梗。
- **模块化的插件接口**：提供各式各样的模块接口，让你培养你自己的辉夜。
